# 博览群书语言
《博览群书语言》v1.0 是《玖柠》的中文语言学开放教材，收录 263 篇，从语言的结构与历史出发，读到各地的文字、碑铭、诗歌和语法书。终章用 12 节讲解 AI 如何处理语言、调用工具并结合图像与动作。
